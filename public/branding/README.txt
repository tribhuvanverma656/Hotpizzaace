Google sign-in brand assets
Retrieved 23 October 2026 from Google's official sources.

google-g.png is the unmodified current gradient G supplied by:
https://developers.google.com/static/identity/images/g-logo.png
Branding requirements:
https://developers.google.com/identity/branding-guidelines

The button uses the Google Sans Medium Latin subset, served locally from:
/fonts/google-sans-latin-500.woff2
Original font stylesheet:
https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap
Google Fonts project metadata and license:
https://github.com/google/fonts/tree/main/ofl/googlesans
The SIL Open Font License is included at /fonts/OFL-GoogleSans.txt.

Assets are served from this website; rendering these buttons does not load a
remote Google image, font stylesheet, or Google Identity Services script.
The existing Supabase OAuth flow handles sign-in separately.
